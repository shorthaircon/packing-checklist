# 出國行李清單 · 視覺識別規範（精簡版）

個人使用的 PWA，只定義核心識別。所有視覺修改以本文件為準；沒寫到的，沿用 `style.css` 既有做法。

核心意象：**復古行李箱**——米白箱體、焦糖皮革、天空藍背景。風格描述用「旅行手帳風」「紙張質感」。

---

## 1. 標誌（App Icon）

- 原稿：`icons/icon-source.svg`（一般）、`icons/icon-maskable-source.svg`（Android 滿版）
- 構成：天空藍圓角底 + 直立米白行李箱 + 焦糖提把／L 型弧形包角／兩條皮帶與扣環 + 墨色輪子
- 網頁頁首**不放** logo，只用文字標題
- 改 icon 流程：改 SVG → 同步 `icons/render-*.html` → 重新輸出 PNG（192 / 512 / maskable 512 / apple 180）→ `service-worker.js` 的 `VERSION` +1
- Maskable 版主體必須落在中心半徑 40% 的圓內

## 2. 標準色

| 角色 | Token | 色碼 | 用途 |
|---|---|---|---|
| 紙張 | `--paper-bg` | `#FAF6EB` | 頁面底色、頁首 |
| 箱體米白 | `--card-bg` | `#FFFCF4` | 卡片、選單 |
| 天空藍（品牌主色） | `--sky` | `#7EC8E3` | App icon 底色、進度條軌道（`--sky-soft`） |
| 焦糖皮革 | `--leather` | `#C98A4B` | 包角、皮帶、扣環、勾選框、頁首底線 |
| 皮革文字 | `--leather-deep` | `#8A5A2B` | 焦糖系的文字（對米白 5.7:1） |
| 皮革淺底 | `--leather-soft` | `#F1DEC7` | 數字膠囊、選取中的清單 |
| 墨色 | `--ink` | `#2A2E33` | 主要文字、勾選框的勾 |
| 夕陽紅 | `--sunset` | `#C85C5C` | **只用於**「重要／警示」：最終檢查按鈕、重要分類 |

**比例**：米白系約 60%、天空藍約 30%（含 icon）、焦糖約 10%。

**對比規則**
- `--leather` 不可當文字色或放淺色文字（對米白只有 2.8:1）；文字一律用 `--leather-deep`
- 焦糖底上的圖形用墨色（4.7:1），不用米白
- 太陽黃 `--sun` 已降為輔助色，不再當主要點綴

## 3. 標準字

| Token | 字體 | 用途 |
|---|---|---|
| `--font-hand` | LXGW WenKai TC | 標題、分類名稱、按鈕 |
| `--font-sans` | Noto Serif TC | 內文、數字 |

不新增字體。

## 4. 輔助圖形（從 icon 拆出）

- **皮革包角**：卡片與選單四角，30px 方塊內挖半徑 22px 的弧形缺口，純焦糖色、無鉚釘、無陰影。icon 的包角同比例（46px 挖 34px）
- **皮帶 + 扣環**：分類標題下方 4px 焦糖帶；扣環 12×16px、圓角 5px，外圈 2px 米白
- **頁首底線**：4px 實線焦糖
- **雲朵、紙飛機**：保留（天空與旅行意象）

## 5. 應用規則

- **對齊**：分類圖示寬 24px，與勾選框、扣環中心在同一條垂直線
- **重要分類**：夕陽紅虛線框 +「！」圖示，圖示放在數字膠囊左側
- **勾選框**：未勾是灰框白底；勾選後焦糖底 + 墨色勾
- **進度條**：軌道天空淺藍，填色米白 → 焦糖漸層，紙飛機在填色末端
- **清單切換**：點標題「清單名稱 ▾」展開下拉選單，選中的那列用 `--leather-soft` 底 + 焦糖圓點
- **觸控目標**：一律 ≥ 44px
- **禁止**：標題旁加 logo、焦糖當文字色、夕陽紅用在非警示用途
